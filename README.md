# Site Pracy.com.br

Site profissional redesenhado para Pracy - Dubladora, Cantora, Compositora e Criadora de Conteúdo.

## Stack

- **Framework:** Next.js 14 (App Router)
- **Estilização:** TailwindCSS
- **Animações:** Framer Motion
- **Ícones:** Lucide React

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse: http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy

Configurado para deploy na VPS via Easypanel.

## Estrutura

- `/app` - Páginas e rotas (Next.js App Router)
- `/components` - Componentes React
- `/public` - Assets estáticos
- `/styles` - Estilos globais
